# Requirements

Students, educators, and electronics enthusiasts need an accessible way to learn digital logic and processor architecture without installing specialist desktop software or purchasing hardware. Interactive Chip Lab will let users design, simulate, debug, save, and share digital circuits and simplified microprocessors directly in a modern browser, while guided lessons connect theory to hands-on experiments.

Build a working tutorial application for Interactive Chip Simulation and Education website. It should let users complete the main workflow from start to finish, review and update the information they need, and receive clear feedback for successful and unsuccessful actions. Use realistic sample data, validate user input, protect sensitive information, work on desktop and mobile screens, and include automated tests for the main workflow.
